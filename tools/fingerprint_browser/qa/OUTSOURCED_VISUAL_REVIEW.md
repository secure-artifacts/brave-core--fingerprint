## 一、必须遵守

### 1. 去哪里审核

必须使用项目提供的截图审批网页：

```text
visual-review.html
```

当前项目中的完整地址：


收到审核包后，必须保留以下目录结构：

```text

```

直接用浏览器打开 `visual-review.html`。不要移动、重命名或单独发送 HTML，否则截图可能无法加载。

本批应显示：

```text

浏览器原生 UI：46 张
```

如果数量不是 137 张，立即停止审核并通知项目负责人。

### 2. 审核结果如何返回

每张截图必须在审批网页中选择：

- `通过`
- `不通过`

选择“不通过”时，必须填写：

- 问题位置。
- 问题表现。
- 正确预期。
- 严重程度：P0、P1、P2 或 P3。

全部审核完成后：

1. 确认“待审批”数量为 `0`。
2. 确认“通过 + 不通过 = 137”。
3. 点击页面中的“导出审批 JSON”。
4. 将导出的 JSON 文件返回给项目负责人。
5. 另外提交所有“不通过”项目的问题清单。
6. P0、P1 问题必须附带标注截图。

最终必须返回：

```text
1. 审批页面导出的 JSON
2. 不通过问题清单
3. P0/P1 标注截图
4. 审核统计
5. 审核人和完成时间
```

审核统计格式：

```text

通过：
不通过：
待审批：0
P0：
P1：
P2：
P3：
审核人：
完成时间：
```

### 3. 必须一张张严格审核

禁止抽样，禁止批量通过。

具体要求：

- 必须审核全部 137 张。
- 每张都要点击进入 Lightbox 放大查看。
- 必须检查截图完整区域，不能只看缩略图。
- 禁止使用“全部通过”功能。
- 禁止未查看截图就选择“通过”。
- 相似截图也必须分别审核。
- 浅色、深色和不同尺寸必须分别审核。
- 不允许保留任何“待审批”项目。
- 审核人需要对每一项结果负责。

发现疑似问题时，应标记“不通过”。不能因为不确定而直接通过。

## 二、重点检查内容

每张截图检查：

- 页面是否空白或崩溃。
- 是否出现 `Aw, Snap!`。
- 文字是否截断、重叠或超出容器。
- 按钮、输入框和图标是否错位。
- 是否存在横向滚动或内容越界。
- 深色和浅色主题是否清晰。
- 正文对比度是否达到约 `4.5:1`。
- 图标、按钮边框是否达到约 `3:1`。
- 非错误状态是否出现刺眼纯红色。
- `Action Required` 是否清晰可读。
- 代理按钮和国家国旗是否清晰。
- 代理成功、失败、过期、冲突状态是否容易区分。
- 指纹“匹配、不同、不可用”状态是否清楚。
- 自研功能是否全部使用简体中文。
- 页面是否可以作为正式视觉基线。

第三方页面内容可能动态变化。Google、Facebook、CreepJS、FingerprintJS、BrowserLeaks 等页面主要检查：

- 是否正常加载。
- 是否空白。
- 是否崩溃。
- 是否出现明显渲染错误。

不要求第三方网站内容与历史截图完全一致。

## 三、通过标准

只有同时满足以下条件才能标记“通过”：

- 完整放大查看过截图。
- 没有发现布局问题。
- 没有发现可读性问题。
- 没有发现异常颜色。
- 没有发现残留英文 UI。
- 没有发现崩溃或空白。
- 截图可以作为后续视觉基线。

通过说明可填写：

```text
界面显示正常，未发现截断、重叠、颜色或可读性问题。
```

## 四、不通过标准

发现以下任一情况必须标记“不通过”：

- 页面崩溃、空白或加载失败。
- 文字看不清、被截断或重叠。
- 按钮不可读或被遮挡。
- 图标错位、变形或颜色刺眼。
- 非错误状态出现纯红色。
- 状态颜色容易造成误判。
- 简体中文页面出现不应存在的英文。
- 不同尺寸下布局损坏。
- 深色或浅色主题不可读。
- 浏览器工具栏、弹窗或菜单显示异常。

合格的问题说明示例：

```text
截图：native/full-dark-proxy-1280x800.png
状态：不通过
严重程度：P1
问题：右上角代理按钮文字与背景对比度不足，深色主题下难以辨认。
预期：提高文字亮度或调整按钮背景，确保按钮清晰可读。
```

禁止只写：

```text
不好看
有问题
颜色不对
需要优化
```

## 五、严重程度

- `P0`：页面崩溃、空白、主要功能无法使用。
- `P1`：文字不可读、按钮不可操作、严重重叠、状态容易误判。
- `P2`：局部截断、间距异常、图标错位、明显视觉不一致。
- `P3`：轻微美观问题，不影响理解和操作。

## 六、本批不包含

以下三类原生截图后续单独审核：

- 崩溃恢复提示。
- 帮助菜单中的诊断导出入口。
- macOS 诊断包保存弹窗。

不得把这三项记录为本批已审核。
