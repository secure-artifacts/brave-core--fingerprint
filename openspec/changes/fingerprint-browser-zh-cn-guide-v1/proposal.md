# 指纹浏览器简体中文指南与 UI 中文化

## 背景

指纹浏览器新增的代理、指纹检测和崩溃诊断功能目前混有英文文案，普通用户也缺少一个统一、可长期找到的使用入口。目标用户只使用简体中文，因此自研功能不应随 Brave 主界面语言切换。

## 目标

- 新增静态 `brave://fingerprint-guide/` 使用指南。
- 从帮助菜单及所有自研功能页面进入指南，不自动打开。
- 代理设置、工具栏状态、指纹检测和诊断导出始终显示简体中文。
- 用稳定状态码替代代理后端传给 UI 的英文句子，并迁移旧 Profile 状态。
- 保持普通 Brave 页面、机器日志和诊断包结构兼容。

## 非目标

- 不翻译 Brave/Chromium 原生页面。
- 不增加固定工具栏按钮。
- 不修改代理、Persona、诊断包的核心行为。
- 不把机器字段、协议名、IANA 时区或文件名翻译成中文。
