## 这是什么软件

一个基于 Chromium 内核定制的浏览器。和普通浏览器的区别在于，它的“用户配置文件”是真正隔离的身份单位。

普通浏览器里，你新开一个窗口、切到无痕模式、甚至在同一台电脑上装两个不同品牌的浏览器，网站看到的设备特征几乎没变。在这里，每新建一个用户配置文件，就等于多了一台配置不同的电脑：

| 隔离的内容 | 说明 |
| --- | --- |
| 设备指纹 | 系统、屏幕、显卡、字体、CPU 核心数等一整套参数各不相同 |
| 登录状态 | Cookie、本地存储、缓存完全分开 |
| 网络出口 | 每个配置文件单独设置代理，走不同的 IP |

## 它解决什么问题

在同一台电脑上登录同一个平台的多个账号，平台通常能看出这些账号来自同一个人，接着就是限流、验证、关联封禁。

麻烦在于常见的隔离手段基本没用。无痕窗口只清 Cookie，设备特征原封不动；清理浏览器数据同理；换个品牌的浏览器，底层硬件和系统信息还是那一套。只挂代理换 IP 也不行，设备特征没变，看起来更像同一台机器在不停换 IP。

要隔离的是两样东西，设备身份和网络出口，而且这两样得同时可信、互相对得上。

## 什么是浏览器指纹

你打开网页时，页面里的脚本能读走一批看起来无害的信息。单看任何一项都认不出你，但几十项凑在一起，重合的人就很少了。

这有点像描述一个人。只说“戴眼镜”没什么意义，但“戴眼镜、身高 178、左撇子、说话带口音、无名指有疤”，范围一下就缩到很小。

### 网站读走了什么

最简单的一类是浏览器主动提供的属性，一行代码就能拿到：User-Agent 和 UA-CH、屏幕分辨率和色深、语言列表、时区、CPU 核心数、设备内存、最大触点数。

麻烦的是第二类，让浏览器先干点活再看结果。Canvas 会让浏览器画一段文字或图形，然后取画出来的像素哈希，不同显卡、驱动和字体渲染引擎画出来的东西有肉眼看不见的差别。WebGL 和 WebGPU 直接问显卡厂商和型号，再渲染一帧比对差异。音频那边用 AudioContext 处理一段声音取输出数值，不同设备的浮点运算末位对不上。这类值伪装起来比属性难得多。

第三类是列清单：系统装了哪些字体，有几个摄像头和麦克风，支持哪些语音合成音色、插件和 MIME 类型。装过设计软件或办公套件的机器，字体清单相当有辨识度。

最后一类看网络：出口 IP 属于哪个国家和运营商，以及 WebRTC 有没有把你真实的本地 IP 漏出去。

前三类回答“你是哪台设备”，最后一类回答“你从哪里上网”。平台一般把两边放在一起看，所以两边都得对得上。

## 这个软件怎么解决

### 指纹取自真实机型

不少工具的做法是给每一项加随机扰动。这么做容易凑出现实中不存在的组合，比如 Windows 的 User-Agent 配上只有 macOS 才有的字体，或者显卡型号和分辨率完全不搭。这种组合本身就是异常信号。

这个浏览器维护了几组取自真实机型的参数池，按操作系统配套抽取：

| 参数池 | 内容 |
| --- | --- |
| 系统与浏览器 | 成套的 User-Agent、UA-CH、平台标识 |
| 图形 | 配套的 WebGL / WebGPU 厂商与渲染器 |
| 硬件 | 屏幕参数、CPU 核心数、设备内存、触点数作为一组 |
| 字体 | 按系统和地区给出的字体清单 |
| 地区 | 语言列表与 accept-language |
| 外设 | 媒体设备、语音合成音色 |

抽到 Windows，整套都是 Windows 的值。抽到某款显卡，屏幕和内存也落在这款机器合理的范围内。

Canvas 和音频这类算出来的指纹，用该身份专属的固定种子做极小扰动。同一个配置文件每次算出来一样，不同配置文件之间不一样。

### 定下来就不再变

每次刷新都在变的指纹，是所有指纹里最可疑的那种。正常用户的设备不会一分钟换一次显卡。

所以这套身份在用户配置文件第一次创建时就定下来，之后长期不变，关闭浏览器、重启电脑都保持原样。想要新身份，新建一个用户配置文件就行。

覆盖的读取面包括设备与系统、屏幕与窗口、Canvas 与 OffscreenCanvas、WebGL 与 WebGPU、WebAudio、字体、媒体设备枚举、语音合成、键盘布局、USB、插件与 MIME、语言与时区、深色模式偏好。

## 代理为什么必须一起用

指纹管“你是哪台设备”，代理管“你从哪里上网”。只做一半，另一半会把你供出去。

最常见的矛盾是这样：出口 IP 在美国，浏览器报的时区却是 GMT+8，语言是简体中文，地理位置在上海。做风控的平台不会看不见这个。

所以代理在这里不是一个单独的开关，而是身份的组成部分：

- 代理绑定在用户配置文件上，不是全局设置，每个配置文件可以走不同的代理。
- 验证代理后，国家、时区、语言、地理位置和 WebRTC 自动跟着出口 IP 走。
- IP 到地理信息的换算用内置的离线数据库完成，不会为了查归属地再向第三方发一次请求，那次请求本身就会暴露你。

配好之后工具栏会显示出口国家的国旗和状态点。看到绿色再登录目标网站。

## 能用在哪

- 社媒和联盟营销多账号：账号之间互不关联，避免连坐。
- 广告投放多账户：不同账户分开，降低关联风险。
- 按地区验证页面：看某个国家的用户实际看到的价格、库存和内容版本。
- 工作和私人账号分开：不用再靠两个浏览器或反复登出。

## 它做不到什么

代理质量差的话，指纹再干净也没用。机房 IP、被大量共享的 IP、已经被标记过的 IP，这些问题指纹解决不了。同理，已经被平台盯上的账号，换一套新身份也救不回来。

账号安全从来不只看设备，平台还会看行为模式、注册信息和使用习惯。这个浏览器让你的多个身份彼此独立，不负责让你在网络上消失。要匿名请用别的工具。

## 先记住两条规则

::: warning 一个平台账号只使用一个用户配置文件
不同账号要用不同用户配置文件。新建窗口或无痕窗口不会产生新身份。
:::

::: tip 先配置代理，再登录目标网站
看到工具栏国旗和绿色状态点后，再登录目标网站。
:::
