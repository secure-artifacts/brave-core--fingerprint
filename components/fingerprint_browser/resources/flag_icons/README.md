# flag-icons atlas

Source: `flag-icons@7.5.0`

Source package SHA-256:
`c0b80bf0e08006a60f56621d6bc49f8c7131f4d1fef6737a165a673431f4b518`

The atlas contains the 249 entries marked `iso: true` in `country.json`,
sorted by lowercase country code. Each cell is 64x48 pixels in a 16x16 grid.
The final seven cells are transparent.
